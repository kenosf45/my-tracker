# My Tracker

A personal weekly time tracker. Start and stop timers or add time by hand, set weekly limits per activity, and see where the week goes (Sunday to Sunday). An activity turns amber when it passes its limit and red once it's more than 1 hour over.

Everything is saved in the browser on the device you use. Nothing is sent to a server. Use **Settings → Backup** to download a backup file or restore one.

Open it at https://kenosf45.github.io/my-tracker/ and add it to your home screen:

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** ⋮ menu → Add to Home screen / Install app

It's a single static page (`index.html`) with a manifest and a small service worker for offline use. No build step.
